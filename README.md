# my-first-extension

Плагин TODO-FIXME, который отображает задачи и проблемы кода в боковой панели. 

## Author

Дергачева Алёна Алексеевна, М3112

## Features

- **Две панели TODO и FIXME.** Задачи сортируются в две независимые вкладки "TODO" и "FIXME".
- **Удаление задач.** При наведении на задачу возникает иконка для удаления задачи. Задача удаляется из панели и из кода одновременно.
- **Синхронизация.** Для обновления списка задач необходимо сохранить файл. 

## Requirements

- Наличие программы VS Code.
- Наличие открытой рабочей области (папки). Плагин сканирует файлы только внутри текущей директории проекта.

## Extension Settings

- Дополнительная настройка не требуется.

## Known Issues

- Плагин поддерживает только поиск ключевых слов "//TODO:" и "//FIXME:". При изменении ключевых слов плагин не будет работать.
